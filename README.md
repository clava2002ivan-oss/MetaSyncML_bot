# Telegram Bot для поиска тиммейтов в Mobile Legends Bang Bang

Этот бот помогает игрокам Mobile Legends Bang Bang найти тиммейтов для совместной игры.

## Функциональность

- ✅ Создание и редактирование анкет игроков
- ✅ Поиск активных тиммейтов
- ✅ Система лайков и мэтчей
- ✅ База данных SQLite для хранения информации
- ✅ Удобный интерфейс с кнопками

## Установка и настройка

### 1. Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 2. Настройка окружения

```bash
# Активируйте виртуальное окружение
source venv/bin/activate

# Установите токен как переменную окружения
export TOKEN="ваш_токен_бота"
```

### 3. Запуск бота

**Вариант 1: Использование скрипта (рекомендуется)**
```bash
# Установите токен
export TOKEN="ваш_токен_бота"

# Запустите бота
./run_bot.sh
```

**Вариант 2: Прямой запуск**
```bash
# Активируйте виртуальное окружение
source venv/bin/activate

# Установите токен
export TOKEN="ваш_токен_бота"

# Запустите бота (оригинальная версия)
python main.py

# Или запустите улучшенную версию
python main_improved.py
```

**Вариант 3: Использование файла .env**
```bash
# Скопируйте пример файла
cp .env.example .env

# Отредактируйте файл .env и добавьте ваш токен
nano .env

# Запустите бота
source venv/bin/activate
python main_improved.py
```

## Использование

### Команды бота:
- `/start` - Начать работу с ботом
- `/help` - Показать справку по использованию
- `/stats` - Показать вашу статистику (только в улучшенной версии)

### Основные функции:
1. **Создание анкеты** - заполните информацию о себе
2. **Быстрый поиск** - найдите активных игроков
3. **Моя анкета** - просмотр и редактирование профиля
4. **Понравился** - посмотрите, кто вас лайкнул
5. **Статистика** - просмотр ваших лайков и мэтчей (только в улучшенной версии)

## Устранение неполадок

### Ошибка "Токен не найден"
```bash
export TOKEN="ваш_токен_от_botfather"
```

### Ошибка "База данных не найдена"
База данных создается автоматически при первом запуске бота.

### Ошибка "Модуль не найден"
```bash
source venv/bin/activate
pip install -r requirements.txt
```
