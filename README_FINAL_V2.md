# MLBB Team Finder Bot - Финальная версия

Бот для поиска тиммейтов в игре Mobile Legends: Bang Bang.

## Описание

MLBB Team Finder - это Telegram бот, который помогает игрокам Mobile Legends находить подходящих союзников для совместной игры. Бот работает от лица персонажа Sil - дружелюбного и компетентного помощника.

## Основные функции

- **Регистрация анкеты**: Создание профиля с информацией о игроке
- **Быстрый поиск**: Поиск активных игроков за последние 3 минуты
- **Система лайков**: Взаимные лайки приводят к мэтчу
- **Управление профилем**: Просмотр, редактирование и удаление анкеты

## Технический стек

- **Язык**: Python 3.12
- **Telegram API**: python-telegram-bot
- **База данных**: SQLite 3
- **Конфигурация**: python-dotenv
- **Сохранение состояний**: StateMemoryStorage

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd mlbb-team-finder
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка токена бота

Создайте файл `.env` в корневой директории проекта:

```env
TOKEN=ваш_токен_бота
```

Как получить токен:
1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

### 4. Запуск бота

#### Локальный запуск
```bash
python main_final_v2.py
```

#### Запуск на PythonAnywhere

1. Загрузите файлы на PythonAnywhere
2. Создайте "Always-on Task" с командой:
```bash
TELEGRAM_TOKEN=ваш_токен python3.12 /home/YourUsername/path/to/main_final_v2.py
```

## Использование

### Регистрация

1. Отправьте `/start` боту
2. Нажмите "🔥 Начать"
3. Заполните анкету:
   - **Игровой ник** (вводится текстом)
   - **Winrate** (0-100%)
   - **Линия** (Голд, Роум, Мид, Лес, Эксп, Везде)
   - **Ранг** (Воин, Элита, Мастер, Грандмастер, Эпик, Легенда, Мифический)
   - **Цель игры**
   - **Описание о себе** (необязательно)
   - **Фото профиля** (необязательно, хранится как file_id)

### Поиск тиммейтов

- **🚀 Быстрый поиск**: Поиск активных игроков за последние 3 минуты
- **⚙️ Поиск тиммейта**: Расширенный поиск с фильтрами (в разработке)

### Система лайков

- Нажимайте "❤️ Нравится" на понравившихся игроков
- При взаимном лайке происходит мэтч
- Оба игрока получают сообщение: "🎉 У вас мэтч! Вот контакт: @username"

## Особенности реализации

### Ключевые функции согласно уточнениям

1. **Регистрация**: Ник вводится текстом, линии на кнопках
2. **Активность**: 3 минуты, обновляется при каждом действии пользователя
3. **Быстрый поиск**: По рангу и активности, вывод по одной анкете с кнопками
4. **Мэтч**: Прямое указание контакта в формате @username
5. **Перезапуск**: StateMemoryStorage для сохранения состояний
6. **Фото**: Хранение как file_id (экономит место)
7. **Интерфейс**: Полностью на русском языке

### Архитектура

- **Модульная структура**: Разделение логики на модули
- **Единый экземпляр БД**: Глобальный экземпляр класса Database
- **Сохранение состояний**: StateMemoryStorage для работы кнопок после перезапуска
- **Обработка ошибок**: Graceful handling ошибок и перезапуск
- **Индексы БД**: Оптимизация производительности запросов

## Развертывание на PythonAnywhere

### Требования

- Платная подписка PythonAnywhere (Hacker или выше)
- Доступ к внешним ресурсам для работы с Telegram API

### Шаги развертывания

1. Загрузите файлы на PythonAnywhere
2. Установите зависимости:
```bash
pip install --user pyTelegramBotAPI python-dotenv
```

3. Создайте "Always-on Task":
   - Перейдите в раздел "Tasks"
   - Создайте новую задачу
   - Команда: `TELEGRAM_TOKEN=ваш_токен python3.12 /home/YourUsername/path/to/main_final_v2.py`
   - Нажмите "Create"

4. Запустите задачу

### Обновление кода

Для обновления бота:
1. Загрузите новые версии файлов
2. Перезапустите "Always-on Task" через веб-интерфейс
